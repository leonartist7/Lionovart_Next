# LIONOVART — Reference-led website system · v1.0

Use the four owner references as the visual authority: 01 transition, 02 information, 03 hero, 04 services. The full system is saved in `DESIGN_SYSTEM.md`; this is the concise generation brief. Updated 7 October 2026.

## Confirmed identity

Clash Display 700 for large bold headings; Clash Display 400/500 for descriptions, body and controls. Playfair Display Italic 400 for brief expressive accents. Never default body copy to DM Sans. Preserve visible word spaces and real font weights; the supplied bold font benefits from about 0.08em extra word spacing in uppercase headings. Avoid making every heading the same bold-plus-italic construction.

Warm cream content and a dramatic black brand scene belong to the same identity. Cream supports the gallery, services, results and explanation; black supports an opening or final statement. Vivid red directs action. Metallic champagne, bronze and silver frame edges or a transition. Keep the center clear. Decoration is purposeful and sparse.

## Working tokens

Canvas #F5F0EB; lighter paper #F7F4EF; raised #FCF9F5. Ink #111111; muted #66615B. Night #0D0D0D; deep night #080909; white #FFFFFF; muted inverse #C9C1B7. Brand red #E5192A; small red text/hover #C51625. Gold #D6AE68, bronze #6F4E2A, pale gold #F3DEB2, silver #DDD6CC.

White on brand red has 4.66:1 contrast. Brand red on cream has 4.12:1: use the darker red-text token for small text. Gold on cream is decorative only. Avoid lightening red CTA backgrounds beneath small white text. Focus: 2px red-text ring with 4px offset on cream, pale gold on dark.

Maximum content width 1328px. Desktop/tablet/mobile gutters 56/32/20px; 16px at 320px. Section gaps 80–112px desktop / 48–64px mobile. Work intro 32–56px. Media radius 24px desktop / 18px mobile; panels 20px; labels 6px; capsule buttons. Most text sections need no enclosing card or shadow.

Hero headings 88–132px desktop / 44–64px mobile. Section headings 48–72 / 32–44. Compact Work heading 48–64 / 32–40. Heading tracking around −0.025em, never enough to merge words. Body 18px desktop / 16–18px mobile, line-height 1.5–1.65. Controls 14–16px; labels 12–13px. Tune responsive values to content and French translations.

## Work page decisions to preserve

Compact introduction; work visible immediately. Two media columns desktop, one mobile. Industry choices always visible and wrapping, no horizontal scrollbar. Services in a separate refinement panel with Apply/Cancel. Controlled single-select groups, All reset, URL-driven state. No search, visible result count or curated-order label.

Media-only cards: all assigned services bottom left on warm backing; pause/play top right. No caption row, visible brand-name caption, industry caption, Film badge, duration, arrow or click-through. Preserve accessible project names, muted looping autoplay, offscreen pausing, manual pause, poster fallback and reduced-motion behavior.

Retain JellyRadio elasticity. Source spring: stiffness 580, jelly 1, bounce .25, stagger 22ms. Wrapped implementation: effective 8% selected swell, zero sideways neighbor movement, no inactive target shrink, 12px gaps, 7px/8px padding. Keep 44px targets and visible focus. Resize events must not cancel the click spring. Reduced motion is static. Do not disable all animation merely to support wrapping.

## Story and proof

Relevant work → attributed results → what happens next → founder/contact context → enquiry. Each section answers a different question. The current Work page replaces the repetitive approach/comparison pair with client stories and clear next steps. A comparison remains a valid optional pattern elsewhere when it answers a distinct decision.

The owner cleared existing testimonials/results on 6 October. Preserve attribution, exact qualifiers and timeframe. Never turn “nearly doubled” into an exact 2× or silently promote an estimate to measured data. No new claims from reference-image promotional text. Display relevant industry stories first; label any cross-industry examples honestly.

Enquiry is primary. Booking is an alternative. Audit is optional and subordinate. Forms must state the actual action: opening an email draft does not mean a message was sent. No forced voice/AI step, intro animation or questionnaire.
